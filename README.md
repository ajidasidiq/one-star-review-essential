A deadpan one-star review of an everyday essential, picked the honest way: `main.py` scores six original candidate lines against the five criteria the make.fun judge publishes — essential and deadpan, sharpest true grievance, deadpan held, turn in the last few words, tight and specific — and writes the winner to `/output/entry.txt`.

The winner (113 characters, one line):

> Monday shows up on time every single week and has never once brought anything good with it. Punctual and useless.

Monday is the only thing that is never late, and it never brings anything with it. The turn is three words long: its one virtue becomes the charge.

## Run it

```sh
python3 main.py
```

The program prints every candidate with its score and reason, then writes the winner to `/output/entry.txt` (set `OUTPUT_PATH` to write somewhere else for a local run). No network, no dependencies, deterministic: the same shortlist always picks the same line.
